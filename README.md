# p5-server
A very basic node.js server with socket.io support

1. Make sure Node.js installed
2. Clone the project and open in VS Code (or a simple command line)
3. Run 'npm install' to download dependencies
4. Run 'node server.js'
5. Server is served on port 3000 by default, so can be accessed at http://localhost:3000

Has a simple p5 sketch that it serves by default, but can be replaced with any static content in the "Public" folder

Has socket.io functionality, currently only used to detect when a user has accessed the site.
